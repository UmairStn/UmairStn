### 🚀 Featured Projects

**[TradeVision](https://github.com/UmairStn/TradeVision)** - Full-stack CSE stock analysis & ML prediction platform
Live quotes, charts, watchlists, and portfolios for the Colombo Stock Exchange, backed by an XGBoost regression model predicting next-day returns (with strict train/inference feature parity) and a FinBERT sentiment pipeline feeding a tool-calling AI chat (Gemini, DeepSeek fallback).
`React 19` `TypeScript` `FastAPI` `XGBoost` `FinBERT` `Supabase`

**[AI RAG Chatbot SaaS](https://github.com/UmairStn/rag-chatbot)** - Multi-tenant retrieval-augmented chatbot platform
Ingests any website's content in minutes via automated scraping, with per-tenant data isolation and a hybrid semantic + keyword retrieval pipeline. Ships as a drop-in embeddable widget using Shadow DOM.
`FastAPI` `Vector DB` `Docker` `Shadow DOM`

**[Roamly](https://github.com/UmairStn/Trip-planner)** - AI-powered multi-day trip planner
Generates complete multi-day itineraries via the Gemini API, cutting manual research from hours to seconds. Uses WSO2 Asgardeo for centralized auth and Redis-based rate limiting to control LLM API costs under load.
`Node.js` `Express` `Gemini API` `Redis` `OAuth2`

**[ShoeStore Microservices](https://github.com/UmairStn/ShoeStore-Microservices)** - Decoupled e-commerce backend
Spring Boot microservices platform with three isolated MySQL databases (one per service) and a React/Tailwind frontend.
`Java` `Spring Boot` `React` `MySQL`
